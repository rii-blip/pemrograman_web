Pengantar Semantic HTML

Semantic HTML adalah pendekatan dalam menulis HTML yang fokus pada makna dan struktur konten, bukan hanya tampilan.

Contoh Tag Semantic

Beberapa tag semantic antara lain: header, nav, main, section, article, aside dan footer.

Informasi Tambahan

Semantic HTML membantu SEO dan aksesibilitas website.
